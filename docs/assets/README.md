# Brand assets

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | README header (GitHub picks one to match the viewer's theme) |
| `icon.svg`, `icon-512.png` | Avatar, favicon, workbook cover |
| `social-preview.png` | GitHub: Settings > General > Social preview |

The icon is a miniature schedule: a title band and three rows on a 12-unit grid.
Every row has a copper tag cell and ends flush right, but its cells span different
numbers of grid units. That is the idea behind kitlist (ADR 0001).

Colours: navy `#1F3A5F`, copper `#D9782D`, pale `#E8EEF5`, band `#8FA7C4`.

All files are generated by `tools/brand/make_logo.py`; edit the script, not the files.
Text is converted to outlines, so nothing depends on installed fonts. The typeface is
IBM Plex Mono, used under the SIL Open Font License (`OFL-IBMPlexMono.txt`).
