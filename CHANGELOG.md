### Added
- Project named `kitlist`; README describes scope, design and roadmap.
- Logo, icon and social preview, generated by `tools/brand/make_logo.py`.
- `docs/requirements.md` with numbered requirements and open questions.
- `layout.yaml` and the grid engine (`kitlist.grid`): field positions and merged header cells for six equipment types, validated on load.
- `kitlist preview` command: writes all schedules, stacked and aligned, to one sheet with a named range per table.
- ADR 0003 (layout as data).
- Repo scaffold: `uv` project, `pytest`, `ruff`, GitHub Actions CI.
- `kitlist.sizing.next_standard_size`: smallest standard size covering load plus spare.
- ADR 0001 (shared 24-column grid) and ADR 0002 (Python reference, Excel formulas at runtime).
